# 영양 섭취 및 운동 추천 웹 애플리케이션 
### 프로젝트 개요

- 사용자가 섭취한 음식과 성별을 입력하면, 일일 권장 칼로리와 비교하여 섭취량을 분석하고, 그에 따른 운동 또는 추가 섭취 음식을 추천해주는 건강 관리 웹 애플리케이션입니다.
