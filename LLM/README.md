# 영화정보 챗봇 프로그램
### 프로젝트 개요

- TMDB API와 Ollama LLM을 활용하여 영화 및 드라마 정보를 실시간으로 검색하고 AI가 상세한 설명을 제공하는 웹 기반 챗봇 프로그램입니다.

### 프로젝트 개발 기간 : 2025.06.16 - 2025.07.11 ( 총 3 일 )
